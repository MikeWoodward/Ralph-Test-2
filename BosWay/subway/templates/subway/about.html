BosWay

about

BosWay is a subway rider reference for checking Boston-area lines, alerts, station facilities, and upcoming train predictions.

Author

Mike Woodward

External services

  • MBTA V3 API for subway lines, alerts, and predictions
  • OpenStreetMap for the basemap tiles and map data
  • Leaflet.js for the interactive map interface

MBTA acknowledgment

BosWay uses Massachusetts Bay Transportation Authority data to support this subway experience.

View official subway schedules on the MBTA subway schedules page .
