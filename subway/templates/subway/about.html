About This App

MBTA Subway is a web application that displays real-time information about the Massachusetts Bay Transportation Authority subway system, including train predictions, service alerts, station facilities, and an interactive map.

External Services

  • MBTA V3 API — Real-time transit data provided by the MBTA V3 API.
  • Leaflet.js — Interactive maps powered by Leaflet (BSD 2-Clause License).
  • OpenStreetMap — Map tiles provided by OpenStreetMap contributors (ODbL).
