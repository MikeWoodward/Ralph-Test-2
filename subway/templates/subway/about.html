About MBTA Subway Explorer

MBTA Subway Explorer is a web application for viewing real-time train predictions, service alerts, station facilities, and subway maps for the Massachusetts Bay Transportation Authority (MBTA) rapid transit system.

External Services

MBTA V3 API

Real-time subway data including train predictions, service alerts, station information, and route geometry are provided by the MBTA V3 API.

Developer Portal · Terms of Use

OpenStreetMap

Map tiles are provided by OpenStreetMap, a collaborative project to create a free editable geographic database of the world.

openstreetmap.org · Terms of Use

Leaflet.js

Interactive maps are rendered using Leaflet.js (v1.9.4), an open-source JavaScript library for mobile-friendly maps.
