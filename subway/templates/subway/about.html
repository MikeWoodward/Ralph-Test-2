About This App

MBTA Subway is a web application that displays real-time information about the Massachusetts Bay Transportation Authority subway system, including train predictions, service alerts, station facilities, and an interactive map.

External Services

  • MBTA V3 API — Real-time transit data provided by the MBTA V3 API, offered under the MassDOT Developers License Agreement. MBTA data attribution is displayed in the map attribution control on every map view.
  • Leaflet.js — Interactive maps powered by Leaflet, released under the BSD 2-Clause License. Leaflet attribution is automatically shown in the map control.
  • OpenStreetMap — Map tiles provided by OpenStreetMap contributors under the Open Data Commons Open Database License (ODbL). Tile usage complies with the OSM Tile Usage Policy. © OpenStreetMap contributors attribution is displayed on every map view.

Attribution

All map views in this application display attribution for data and tile providers in the lower-right corner of the map, crediting the MBTA V3 API for transit data, OpenStreetMap contributors for map tiles, and Leaflet for the map library.
